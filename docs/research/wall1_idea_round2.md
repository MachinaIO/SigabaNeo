## Coordinate prefix theorem and its proof

The six cubic freezes through column 511 leave $q\mathbb Z^{505}$. Force a coordinate freeze on each successive graph append until time $h\le105$. Immediately before forced freeze $t$, deleting already frozen coordinates gives the actual Euclidean coordinate metric on $b$ coordinates. The forced window is
$$
 W_t=\{(x,y)\in\mathbb Z^{b-t}\oplus\mathbb Z^t:x=B_ty\pmod q\},
$$
where $B_t$ takes the surviving horizontal rows and first $t$ graph columns of $A$. This follows by deleting the earliest surviving horizontal coordinate each time. The row and column labels are deterministic in this auxiliary path, so $B_t$ is uniform marginally even though the $B_t$ are dependent. The window contains every $q$-axis. If no other vector has length at most $q$, signed lexicographic minimization selects the negative earliest horizontal axis. Its projection is coordinate deletion. Counting ties as possible disagreements is conservative.

For a nonaxis candidate of length at most $q$ in $W_t$, $y\bmod q$ must be nonzero: otherwise all coordinates are divisible by $q$. For a fixed such label each row gives one independent uniform equation, with joint probability $q^{-(b-t)}$. Count sign pairs. Disjoint unit cubes around integer points of the closed ball fit inside the ball of radius $q+\sqrt b/2$. By Markov and a union bound for the first possible disagreement,
$$
 \Pr(\text{disagreement through }h)
 \le B(h)=\tfrac12 V_b(1+\sqrt b/(2q))^b\sum_{t=1}^h q^t .
$$
No conditional uniformity of an old column was used. At $h=105$, $0.00022303<B(h)<0.00022304$. The same bound with $h=106$ exceeds 0.74, so extending by even one step needs different counting or a different error budget.

After 105 deletions the retained graph has 400 horizontal and 105 vertical coordinates, mark generated by the 400 horizontal unit classes, and determinant $q^{400}$. These classes are independent over $\mathbb F_q$ since the graph intersects the horizontal coordinate space in $q\mathbb Z^{400}$. Each subsequent column consists of a uniform 400-vector of residues and its own new unit coordinate. The ignored rows have zero projection on the forced path. Start this smaller process with the marginal uniform matrix, use the same suffix residues, retain coordinate order, and run exactly the remaining Part 108 transitions. On agreement the two terminal lattices are isometric, including determinant. Therefore for **every** terminal shape event the absolute difference of probabilities is at most $B(105)$. In particular a reduced-experiment failure bound of **0.00977696** suffices. Sampling the smaller matrix *conditioned* on coordinate success would generally bias its law. This coupling pays for the entire bias once. It does not refresh any later window or assert that its shape is Haar.

## Reproduction of rounding bounds

The following Python uses interval endpoints throughout. All scale constants refer to the physical graph before determinant normalization.

```python
from mpmath import iv
iv.dps = 40
I, log = iv.mpf, iv.ln
b, d, q = 506, 505, 3329
a = I(d)/b
def V(j):
    return iv.pi**(I(j)/2)/iv.gamma(1+I(j)/2)
def G(j):
    return V(j)**(-I(1)/j)
def cost(h):
    return V(b)*(1+iv.sqrt(b)/(2*q))**b*sum(q**t for t in range(1,h+1))/2
assert I('.00022303') < cost(105) < I('.00022304')
assert cost(106) > I('.74')
weight = b*(1-a**407)
p = d*I(511)/1023*log(q)-400*a**407*log(q)+weight*log(G(b))
assert I('1071.78') < p < I('1071.79')
assert iv.exp((I('547.8033')-p)/weight) < I('.154')
c = I('.954')
assert (2*c*G(d)/iv.sqrt(3))**a/G(b) < I('1.097')
ref, target = I('2.35e-11'), I('.01')
assert c**d/2 < ref
kl = target*log(target/ref)+(1-target)*log((1-target)/(1-ref))
assert I('.188') < kl < I('.190')
assert 105*log(q) > 851 and q**105 > 10**369
```

The unresolved estimate is an average over the 400-row initial graph and the 407 fresh columns. Neither the determinant recursion nor coordinate agreement estimates the lower tail on that suffix.
