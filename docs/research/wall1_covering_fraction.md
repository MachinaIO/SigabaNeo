# Conditional coverage for a fresh BKZ column

Use the size-reduced triangular chart at fixed positive GS lengths, with independent uniform fresh GS coefficients. All radii below are in ambient determinant-one units. The unconditional lattice law in the numerical theorem is Haar. Let \(a=\max(0,j-b+1)\). For \(a\le i<j\), let \(P_i\) discard coordinates before \(i\) in the first \(j\) GS coordinates. Then \(\Lambda_i=P_iD_j\) is generated by the projected columns \(i,\ldots,j-1\). Write \(B_i(r)\) for the image of the open Euclidean ball in its torus, empty at zero. The exact forbidden set in the full prefix torus is
\[
 F_j=\bigcup_{i=a}^{j-1}\ \bigcup_{1\le m<g_i/g_j}
 (mP_i)^{-1}B_i(\sqrt{g_i^2-m^2g_j^2}).
\]
Indeed, for prescribed positive last coefficient the horizontal lifts form one coset and the perpendicular height is \(mg_j\). Negation handles negative coefficients. The start \(i=j\) has no strict competitor. Each displayed map pushes Haar probability to Haar by surjectivity. This describes the fresh tests even for a history that already failed earlier tests.

## A common box for all starts

Backward rounding gives the unique representative of the fresh shift in the centered rectangular GS box, up to null boundaries. Successive elimination of a column changes only earlier coordinates, so the box tiles by the lattice, and its suffix is the box representative for each projected shift. Thus \(X_l=g_l U_l\), with independent \(U_l\) uniform on \([-1/2,1/2]\), simultaneously supplies candidate lifts for all starts. For every history the forbidden fraction is at least
\[
 Q_j=\Pr\{\exists i\in[a,j):\ g_j^2+\sum_{l=i}^{j-1}X_l^2<g_i^2\}.
\]
This finite box integral takes account of the dependence between nested windows. For example any single choice of nonnegative \(t_l\) with \(\sum_{i\le l<j}t_l^2\le g_i^2-g_j^2\) supplies the lower bound \(\prod_{i\le l<j}\min(1,2t_l/g_l)\) (boundary equality costs zero in positive dimension).

If \(g_i^2>g_j^2+\frac14\sum_{i\le l<j}g_l^2\), no shift passes. Equality gives zero pass measure. The strict profile exclusion contributes **no new cut** beyond the two-dimensional constraint. Indeed \(g_{l+1}^2\ge3g_l^2/4\) telescopes to the reverse weak inequality. Equality throughout requires equality on every adjacent pair. This distinction also matters for interpreting a zero Haar weight as a deterministic assertion.

## A strictly additive multiple-coefficient correction

Put \(d=j-a\). If
\[
 g_j^2+\tfrac1{16}\sum_{l=i}^{j-1}g_l^2\ge g_i^2\qquad(a\le i<j),
\]
then a uniform lower bound is
\[
 L_j=Q_j+2^{-d}\Pr\{\exists i\in[a,j):4g_j^2+\sum_{l=i}^{j-1}X_l^2<g_i^2\}.
\]
Otherwise take \(L_j=Q_j\). For the proof, work in the rank-\(d\) projected torus. Conditional on the doubled point, the shift is uniform on its \(2^d\) preimages. In its centered box decode these preimages backwards. At each coordinate, given later choices, there are two equally likely residues separated by half a period: the later carries are fixed and the current lattice coefficient may have either parity. Each choice has the same number of earlier completions. At least one choice has absolute residual at least \(g_l/4\). With conditional probability at least \(2^{-d}\) all coordinates satisfy these lower bounds. Such preimages lie outside the single-coefficient **box** hit event by the displayed hypothesis, while a doubled box hit guarantees an actual competitor there. Integrating proves the addition without independent-multiple assumptions.

For example take \(g_l=(49/50)^l\), \(j=35\), \(b\ge36\). The hypothesis telescopes since \((49/50)^2>15/16\), and \(2(49/50)^{35}<1\) gives a positive open neighborhood of doubled hits. This proves strict improvement over the box bound on this profile. The correction need not be large.

\[
 2^{1-n}K_n\int_{D(\rho)} e^{2\sum S_j}\prod_j(1-L_j)\,dS.
\]
Here \(D\) includes the valid Part 65 packing inequalities. For a reproducible upper integration retain the adjacent hard zeros and one soft interval. On the Part 65 capped orthant \(S\le U\), under the normalized exponential density the deficits are independent rate-two exponentials. For each interior triple the Part 59 event with threshold \(a_j=\max(0,\log(4/3)/2-2U_j+U_{j-1}+U_{j+1})\) forces an adjacent zero. Its probability is \(h_j=e^{-2a_j}(5/9+2a_j/3)\), by integration of the shape-two gamma tail. Define \(h_j^\prime\) by the same formula with \(16/15\) replacing \(4/3\). On its larger triple event the adjacent hit probability is at least one half, by the exact circle interval length. Consequently the expected cube of the adjacent pass factor is at most \(1-h_j-7(h_j^\prime-h_j)/8\). Each residue class modulo three uses disjoint triples.  A_n-2(n-1)\log2+2\sum U_j+\tfrac13\sum_{j=2}^{n-2}\log(1-h_j-7(h_j^\prime-h_j)/8).

### Interval verification

Run from the repository root with Python and mpmath. The dependency is the embedded Part 65 certificate, which both initializes the interval packing envelope and verifies the stronger primitive-chain column.
