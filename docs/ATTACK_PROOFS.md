# Lean proofs of the lattice estimator's attacks: status

The goal is a Lean proof, without `sorry` or `axiom`, of every LWE attack the lattice estimator
considers, and of close variants. Each proof is an explicit algorithm with a proven success
probability and operation count. This page tracks progress per attack. Details and bit gaps are
in [PROOF_GAP.md](PROOF_GAP.md); the cost models are in [LWE_ESTIMATOR.md](LWE_ESTIMATOR.md).

Status marks:

* **proved**: a Lean theorem whose remaining premises are only standard facts that are also
  proved;
* **proved given H**: a Lean theorem with the explicit hypotheses `H` as premises;
* **paper**: an audited paper proof, not yet in Lean;
* **open**: no proof.

| Estimator attack | What a proof needs | Status |
| --- | --- | --- |
| `exhaustive_search` | enumerate the secret's support, check `b − As` short; uniqueness w.h.p. | **proved** (`Attacks/Guess/Collision.lean`). `Guess.ambiguity_probability`: for prime `q`, `n > 0`, a secret in a support of size `S` and any fixed error in `[−B, B]^m`, the scan fails to return exactly the secret with probability `≤ (S−1)(2B+1)^m/q^m` over uniform `A`. `Guess.scan_singleton_iff` identifies the failure event. `Guess.scanMultiplications_eq` counts exactly `S·m·n` ring multiplications; additions and tests are not counted |
| `mitm` | split the secret, hash or round `A₁s₁`, collision search | correctness **proved**: `Mitm.matches_eq_scan`, so the join returns the scan's candidates and inherits the bound above. Cost: `Mitm.balanced_tableOperations` counts `k(1+|E|)` modelled table operations. `Mitm.integerBox_card`: the error box has exactly `(2B+1)^m` guesses. `IndexedLookup.Tree.filter_probe_eq_scan` (bucket filtering equals a full scan for a partitioned tree) and `comparisons_le_depth` (one pivot comparison per level). `filterCount_spec` (bucket filtering: one equality test per row). `leaf_miss` (counterexample: depth alone does not bound lookup cost, so bucket sizes must be bounded too). **End-to-end theorem for the flat-bucket join** (`Mitm/FlatJoin.lean`, `flatJoin_end_to_end`): the output equals `exactJoin`; the singleton-recovery probability is `≥ 1 − (|S|−1)(2B+1)^m/q^m`; exactly `|R|·|E|·|L|` key equality tests. This variant costs about `S`, like exhaustive search. The `√S` runtime needs a sorted index with logarithmic lookup: open |
| `arora-gb` | Arora–Ge linearization: full rank of the linearized system w.h.p. (the Gröbner variant needs semi-regularity, Fröberg's open conjecture) | components: `AroraGe.boundedErrorEquation`; `AroraGe.homogeneous_not_injective` shows the homogeneous form keeping the constant monomial is never injective, so the constant must move to the right-hand side; that rank question, success and cost are open. **Counterexample to the naive full-rank claim** (`AroraGe/Rank.lean`): with `s = 0`, `e = 0`, `n = 1`, `B = 1`, `q = 5`, the sample polynomial is odd (`aX − a³X³`), so every linearized matrix has a kernel (`fullRankCount_mod_five`: 0 of `5^m`). Shifting the secret does not help either (`AroraGe/Shifted.lean`, `shiftedFullRankCount`: with all errors zero, 0 matrix–secret pairs have full rank, kernel witness `(0, 1, 3s)`). Full support alone does not help either (`AroraGe/RandomErrors.lean`, `rankFailureCount`): if the error is 0 with probability `k/(k+2)`, rank fails with probability `≥ (k/(k+2))^m`. **Proved by enumerating consistent assignments**: `consistentScan_failure` gives failure `≤ (q^n − 1)((2B+1)/q)^m`, and `consistentScan_multiplications` counts exactly `q^n m n` multiplications. This is exhaustive search through the Arora–Ge equations, not the polynomial-time linearization. `uniformTranslation_zero_count`: under a uniform error, each fixed coefficient of degree `k ≥ 1` survives with probability `≥ k/D`. **End-to-end for one instance** (`AroraGe/CubicSolver.lean`, `uniform_recovery`): one secret coordinate over `F_5`, 3 samples, uniform errors in `{−1,0,1}`; success probability `≥ 32/3375`, exactly 45 multiplications. Open: general `q`, `n` with random errors (rank bound) and the elimination count. Gröbner: open |
| `bkw` (coded) | plain BKW with fresh samples: bias of summed errors, Chernoff test; coded/LMS variants | components: `Bkw.blockDifference` (subtraction zeroes a block), `Bkw.ErrorTree.residual_bounds` (`|e| ≤ 2^a B`), `Bkw.errorMean_norm` (Fourier bias of a depth-`a` tree is exactly `β^{2^a}` for a finite base law). `Bkw.matchedMass_conditional` (one fresh pair conditioned on a block match factors into a uniform remaining difference and the difference of two independent errors), `errorMean_difference_re` (after one difference the real character mean is `|mean|² ≥ 0`), `zeroStage_negative_mean` (at depth 0 the cosine mean can be −1, so test after ≥ 1 difference). `errorMean_leaves` (depth-`a` expectation as a sum over `2^a` leaf assignments with product weights) and `errorMean_succ` (for `d ≥ 1` the character mean is exactly `|β|^{2^d} ≥ 0`). `retry_mass_eq_filter` (geometric retry weights equal the filtered law). **End-to-end for one-stage binary BKW** (`Bkw/BinaryPair.lean`, `end_to_end`): exact recovery probability `1/2 + (1−2p)²/(4|B|)` for the last bit from one fresh pair, `≤ 5` operations. Open: multi-stage rejection sampling, high-confidence recovery from many pairs, `q`-ary and coded BKW |
| `dual`, `dual_hybrid` | Pouly–Shen-style rigorous dual distinguisher; generating the dual vectors needs walls 1 and 2 | **Proved end to end given a short-dual-direction sampler** (`Dual/Assembled.lean`, `boundedDualTest`): for fresh pairs of a direction (reductions of integer vectors of norm `≤ W₀` in `{w ≢ 0, wᵀA ≡ 0}`) and a right-hand side, with errors that reduce from `[−B, B]^m`, set `ε = 1 − (2π W₀ B √m/q)²/2 > 0`. With `N ≥ 8 log(1/δ)/ε²`, the test `Σ cos ≥ Nε/2` has acceptance gap `≥ 1 − 2δ` (LWE vs uniform), using `N·m` multiplications. The bias is derived (`bounded_dual_bias`, `dotCharacter_cast_re`), not assumed. Remaining premise: the direction sampler, i.e. lattice reduction (walls 1 and 2). Also open: Gaussian (unbounded) errors and a shared right-hand side (`shared_binary_variance` shows the fresh-sample variance bound fails there) |
| `usvp`, `bdd`, hybrids | uniqueness (stage 2) + a solver for the planted shortest vector | uniqueness **proved** (`Planted.badMatrices_probability`); solver: see below |
| — full-dimension sieve on the embedding (the route around walls 1 and 2) | sieve correctness (T1) + the static statistics S1–S3′ for the planted lattice at polynomial `q` | T1 **proved given S1–S4, S3′ and `IdealUniformLeaves`** (`Sieve.prescribedScan_T1`); statistics: paper for random `q`-ary lattices (T4/T4b, audited), obstruction at thin shells and `q = 3329`, wide-shell redesign in progress |
| — BKZ-based (estimator's cheapest) | wall 1 (average BKZ profile) and wall 2 (sieve on BKZ blocks) | open. Parts 1–3 of wall 1 gave an exact pre-BKZ law and two obstructions; part 4 (Gaussian selection) in progress. Worst-case BKZ gives no cost for Kyber |
| sieving cost `2^{0.292β}` itself | assumption (B) | random lattices: T1 in Lean given the static hypotheses; `0.2925` on paper (P′ + audited GFH) |
